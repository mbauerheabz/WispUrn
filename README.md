# WispUrn

WispUrn is a distributed, real-time data processing framework that auto-scaling capabilities for efficient data ingestion and broker-based orchestration.

The key benefits of using WispUrn include:

- WispUrn is a distributed, real-time
- data processing framework that auto-scaling
- capabilities for efficient data ingestion

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/WispUrn.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

WispUrn is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
